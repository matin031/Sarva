# بازطراحی پل وزن — نسخهٔ بررسی محلی

تاریخ: ۲۰۲۶/۰۹/۰۸

برنچ مستقل: `codex/aruz-bridge-redesign`، بر پایهٔ `ca22561`.
این گزارش شواهد بررسی نسخهٔ تأییدشده توسط کاربر را ثبت می‌کند؛ انتشار سایت و ادغام با main جدا از این بررسی‌اند.

## تغییرات

- شخصیت مفصل‌دار با آرنج، زانو، کفش، شال و کوله؛ ژست‌های پرش، فرود و تقلای سقوط از ساعت همان حرکت تغذیه می‌شوند.
- کاهش حرکت برای شخصیت جدید نیز رعایت می‌شود.
- تالار با ستون‌های داخلی، طاق‌های تو‌در‌تو، چراغ، بست و تیرهای مورب زیر پل؛ عمق پایین صحنه با تیرگی تدریجی مشخص می‌شود.
- معماری ثابت در پنج دستهٔ هندسی بر اساس جنس ادغام شده؛ بافت نویز سنگ ۱۲۸×۱۲۸ در حافظه تولید می‌شود و فایل خارجی ندارد.
- لبهٔ شیشه پخ دارد، بست‌ها به شکل L هستند، عبور نور بیشتر است و دورخط نوشته‌های فارسی کمتر شده.
- انتخاب اول‌شخص/سوم‌شخص، دوربین سوم‌شخص در محور مرکزی از بالا، سؤال واقعی، گزینه‌های روی شیشه و منطق پاسخ قبلی حفظ شده‌اند.

## اعتبارسنجی

- TypeScript و ESLint فایل‌های تغییرکرده: موفق.
- ۱۸ تست موجود پل وزن: موفق.
- مرورگر Edge با API واقعی پروژه؛ هیچ پاسخ یا سؤال ساختگی استفاده نشده.
- دسکتاپ اول‌شخص: ده پاسخ درست با کلیک روی خود شیشه، نتیجهٔ «۱۰ از ۱۰».
- دسکتاپ سوم‌شخص، موبایل عمودی، موبایل افقی با کاهش حرکت: یک پاسخ درست و سپس غلط، نتیجهٔ شکست صحیح.
- شناسهٔ کاشی انتخاب‌شده، سمت پاسخ و علامت مختصات مقصد پرش بررسی شدند.
- هیچ خطای pageerror یا سرریز افقی در این سناریوها دیده نشد.

## سنجش عملکرد

Edge headless، Intel UHD، سرور توسعه، بازهٔ ۲٫۲ ثانیه‌ای در سؤال اول، سرعت آرام.
دسکتاپ ۱۲۸۰×۹۰۰ با DPR دستگاه ۲؛ موبایل شبیه‌سازی‌شده ۳۹۰×۸۴۴ با DPR دستگاه ۳.
رزولوشن واقعی بوم در همهٔ حالات حدود ۱٫۵ بود.

| نما | میانهٔ فریم ms | صدک ۹۵ ms | میانهٔ draw calls |
| --- | ---: | ---: | ---: |
| دسکتاپ سوم‌شخص | 16.7 | 33.4 | 103 |
| دسکتاپ اول‌شخص | 16.7 | 33.6 | 117 |
| موبایل شبیه‌سازی‌شده سوم‌شخص | 16.7 | 16.8 | 127 |
| موبایل شبیه‌سازی‌شده اول‌شخص | 16.7 | 16.8 | 121 |

این اندازه‌گیری کوتاه است؛ تضمین ۶۰ فریم ثابت روی همهٔ دستگاه‌ها نیست.
build تولید، گوشی واقعی و آزمون طولانی گرما/باتری انجام نشده‌اند.
سقف DPR و کاهش خودکار رزولوشن نسخهٔ قبلی حفظ شده‌اند.

## اجرای مستقل

نشانی: http://localhost:3107/game/aruz-bridge

پوشهٔ اصلی سروا و برنچ انتخابی کاربر مستقل هستند. این worktree از وابستگی‌های نصب‌شدهٔ همان پروژه با junction استفاده می‌کند.
تنظیم مشروط `SARVA_REVIEW_ROOT` در نسخهٔ محلی `next.config.ts` فقط برای اجرای Turbopack با وابستگی لینک‌شده اضافه شده و از کامیت بازطراحی کنار گذاشته شده است. برای اجرای معمول از وابستگی‌های نصب‌شده در خود پروژه استفاده شود.
فایل محیط محلی و node_modules در Git نادیده گرفته می‌شوند.

شواهد و اسکریپت‌های مرورگر کنار پوشهٔ worktree هستند:
`review-gameplay-results.json`، `redesign-review-bridge-performance.json`، `review-bridge.cjs`، `review-gameplay.cjs` و `measure-review.cjs`.
